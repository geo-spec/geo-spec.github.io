Privacy policy

Last updated: 2026-09-27.

rclone-vm-backup is a personal backup tool used only by its owner.

  • It requests the Google Drive scope drive.file, which only gives access to files the tool itself creates. It cannot see any other files in Google Drive.
  • Backup data is encrypted before upload and is stored only in the owner's own Google Drive.
  • No data is collected, sold, shared with third parties or used for advertising. There are no analytics or cookies.
  • OAuth tokens are stored only on the owner's own machines and are never transmitted anywhere except to Google.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
