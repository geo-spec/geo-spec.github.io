🚀 Click-start: твой новый терминал

Короткий наглядный гайд по окружению. Порядок - от того, что трогаешь каждую минуту, к приятным мелочам. Читать сверху вниз, привыкать по одному пункту.

Одно правило привыкания: не старайся выучить всё сразу. Возьми пункт 1 (поиск истории), поживи с ним день, потом следующий.

1. 🔍 Поиск по истории - Ctrl+R самое полезное

Раньше жал ↑ много раз, чтобы найти старую команду. Теперь жми Ctrl+R и печатай кусок команды - atuin ищет по всей истории с контекстом (когда, в каком каталоге, код выхода).

Ctrl+R - живой поиск, стрелками выбираешь, Enter вставляет.

КлавишиДействие
Ctrl+Rоткрыть поиск, печатай фрагмент
↑ / ↓двигаться по совпадениям
Enterподставить команду (запуск - вторым Enter)
Ctrl+R внутрипереключить фильтр: вся история → хост → сессия → каталог
Старая история уже импортирована (596 команд), искать есть по чему.

2. 👻 Автоподсказки и подсветка

Серый текст после курсора - подсказка по истории. Принять целиком - → или End, одно слово - Alt+→.

Цвет команды: зелёная - найдена, красная - опечатка. Видно ошибку до нажатия Enter. Ничего жать не надо - просто печатай и поглядывай.

3. 🧭 Умный переход по папкам - z

Вместо длинного cd ~/work/projects/foo/bar пиши z bar - zoxide помнит, куда ходишь, и прыгает туда сам.

КомандаЧто делает
z barпрыгнуть в самую частую папку с "bar"
z foo barуточнить двумя кусками пути
ziинтерактивно выбрать из списка
Чем больше ходишь обычным cd, тем умнее z. Обычный cd тоже работает.

4. 📂 Красивый список файлов - ls / ll

ls теперь это eza: иконки, цвета, git-статус файлов.

КомандаЧто делает
lsкомпактный список с иконками
llдлинный: права, размер, дата, git
laто же + скрытые файлы
ltдерево на 2 уровня

5. ⚡ Fuzzy-поиск файлов - Ctrl+T и Alt+C

Ctrl+T - вставить файл в текущую команду нечётким поиском. Alt+C - прыгнуть в подкаталог тем же поиском.

Пример: напиши nvim и жми Ctrl+T - выбери файл, он подставится.

6. 🐈 Просмотр файлов - bat

bat file.py - как cat, но с подсветкой синтаксиса, номерами строк и git-разметкой.

bat -p file - чистый вывод без рамок. Обычный cat оставлен как есть - для пайпов и скриптов.

7. 🛰️ Промпт Starship - читай контекст строки

Слева направо: каталог → git-ветка и статус → версии языков → облачный контекст → длительность прошлой команды.

Сразу видно, в какой ты ветке, есть ли незакоммиченное (!), и в каком профиле сидишь.

9. 🔧 Приятные мелочи

git diff / git show теперь через delta - читаемые цветные диффы. Листать конфликты - n / N.

btop - монитор системы (выход q). tldr <команда> - короткая шпаргалка с примерами вместо длинного man.

✅ Чек-лист привыкания (по одному в день)

  • День 1: искать историю через Ctrl+R вместо долгого ↑↑↑
  • День 2: ходить по папкам через z вместо длинных cd
  • День 3: замечать серые автоподсказки и принимать →
  • День 4: ll вместо ls -la, bat вместо cat
  • День 5: Ctrl+T / Alt+C в командах
  • День 6: сплиты в Ghostty (Cmd+D) вместо кучи вкладок
  • День 7: Quick Terminal Cmd+Ctrl+` как основной способ открыть терминал

🛟 Если что-то не так

  • Промпт/подсказки не появились - открой новую вкладку или exec zsh.
  • Иконки - квадратики: шрифт должен быть JetBrainsMono Nerd Font (в Ghostty уже задан).
  • Где что лежит: конфиги в ~/dotfiles/, промпт - ~/.config/starship.toml, терминал - ~/.config/ghostty/config.
Не жми всё сразу - бери по пункту. Через неделю будет казаться, что так было всегда.
