# geo-spec public pages

Единственный публичный репозиторий `geo-spec` для статических публикаций.

Правило:

- все остальные репозитории `geo-spec` по умолчанию приватные;
- новые публичные статьи, сайты и демо добавляются сюда отдельной папкой;
- адрес публикации имеет вид `https://geo-spec.github.io/<slug>/`;
- старые публичные репозитории считаются временными источниками до проверки и удаления.

Текущие страницы:

- `agent-map/` - короткая карта работы с агентами;
- `agent-playbook/` - полный справочник по работе с агентами;
- `codex-claude-code/` - статья про связку Codex и Claude Code.
